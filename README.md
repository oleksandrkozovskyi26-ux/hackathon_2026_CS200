Coliving Management Telegram Bot (Hackathon 2026 — CS200)

Telegram-бот для автоматизації побуту та фінансового обліку в колівінгу. Проєкт синхронізує графік чергувань і статус щомісячних внесків із Google Таблиць, надає мешканцям швидкий доступ до правил проживання, паролів Wi-Fi, реквізитів оплати та персональних нагадувань.

## Основний функціонал

* **Реєстрація та авторизація мешканців:** прив'язка Telegram ID до профілю мешканця за прізвищем та ім'ям (`/register ПРІЗВИЩЕ ІМ'Я`).
* **Облік щомісячних внесків («Данина»):**
  * Перевірка власного статусу оплати за поточний місяць.
  * Перегляд зведеної таблиці оплат усіх мешканців у зручному моноширинному форматі (`<pre>`).
  * Автоматичний парсинг актуальних даних із Google Sheets.
* **Управління чергуваннями:**
  * Автоматичне розгортання кожної зміни з таблиці у 3-денний період чергування.
  * Пошук найближчих персональних дат чергування та визначення чергового на сьогодні.
  * Потокобезпечна синхронізація дат із локальною базою `members.json`.
* **Довідник колівінгу:** швидкий доступ до умов оплати, посилання на банку Monobank, контактів сотника, даних Wi-Fi мереж, чекліста чергового та внутрішніх правил.

## 🛠 Технологічний стек

* **Мова програмування:** Python 3.10+
* **Telegram API:** `pyTelegramBotAPI` (`telebot`)
* **Валідація даних та схеми:** `pydantic`
* **Інтеграція з Google Sheets:** `requests`, `csv` (експорт таблиць у CSV)
* **Конфігурація та зберігання даних:** `python-dotenv`, JSON

## Структура проєкту

```text
hackathon_2026_CS200/
├── bot.py                        # Точка входу, обробники команд (/start, /register) та кнопок меню
├── duty_service.py               # Сервіс синхронізації та вибірки графіка чергувань (ColivingDutyService)
├── info_service.py               # Сервіс отримання довідкової інформації (ColivingInfoService)
├── service.py                    # Бізнес-логіка обліку бюджету та реєстрації (ColivingBudgetService)
├── schemas.py                    # Pydantic-моделі даних (Member, ColivingInfo)
├── api_to_json_cherguvania.py    # ETL-скрипт імпорту та розрахунку 3-денних чергувань із Google Sheets
├── api_to_json_vkladka.py        # ETL-скрипт імпорту статусів оплат із Google Sheets
├── members.json                  # Локальна база стану мешканців (ID, оплати, дати чергувань)
├── coliving_info.json            # Конфігурація правил, Wi-Fi, контактів та реквізитів колівінгу
├── api_to_json_cherguvania.json  # Згенерований кеш дат чергувань
├── api_to_json_vkladka.json      # Згенерований кеш останніх оплачених місяців
└── .env                          # Змінні оточення (токен бота та ID адміністраторів)
```

## ⚙️ Встановлення та запуск

1. **Клонуйте репозиторій:**
   ```bash
   git clone [https://github.com/oleksandrkozovskyi26-ux/hackathon_2026_CS200.git](https://github.com/oleksandrkozovskyi26-ux/hackathon_2026_CS200.git)
   cd hackathon_2026_CS200
   ```

2. **Створіть віртуальне середовище та встановіть залежності:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install pyTelegramBotAPI pydantic requests python-dotenv
   ```

3. **Налаштуйте змінні оточення:**
   Створіть файл `.env` у корені проєкту та додайте токен вашого Telegram-бота й ID адміністраторів:
   ```env
   BOT_TOKEN=your_telegram_bot_token
   ADMIN_TELEGRAM_IDS=123456789,987654321
   ```

4. **Оновіть дані з Google Таблиць та заповніть довідник:**
   За потреби відредагуйте `coliving_info.json` (назва колівінгу, посилання на банку, Wi-Fi, правила) та запустіть скрипти синхронізації:
   ```bash
   python api_to_json_cherguvania.py
   python api_to_json_vkladka.py
   ```

5. **Запустіть бота:**
   ```bash
   python bot.py
   ```

## 💬 Команди та сценарій використання

1. Користувач запускає бота командою `/start`.
2. Якщо профіль ще не прив'язаний до Telegram ID, бот пропонує зареєструватися командою:
   ```text
   /register ПРІЗВИЩЕ ІМ'Я
   ```
3. Після реєстрації відкривається інтерактивне меню з кнопками:
   * **Інформація про колівінг** — правила, Wi-Fi, контакти та реквізити.
   * **Таблиця Чергування** — загальний графік чергувань мешканців.
   * **Перевірити коли моє чергування** — найближчі дати змін для поточного користувача.
   * **Таблиця данини за Колівінг** — зведена таблиця статусів оплат (`Так` / `Ні`).
   * **Чи заплатив я за колівінг?** — персональна перевірка оплати за поточний місяць.
